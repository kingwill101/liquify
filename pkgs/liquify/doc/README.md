## Quick Start

### Basic Variable Output
```liquid
{{ name }}
{{ user.email }}
{{ products[0].title }}
```

### Basic Control Flow
```liquid
{% if user.logged_in %}
  Welcome back, {{ user.name }}!
{% else %}
  Please log in.
{% endif %}
```

### Basic Iteration
```liquid
{% for product in products %}
  <h3>{{ product.title }}</h3>
  <p>{{ product.description }}</p>
{% endfor %}
```

### Filters
```liquid
{{ "hello world" | capitalize }}
{{ products | size }}
{{ product.created_at | date: "%B %d, %Y" }}
```
